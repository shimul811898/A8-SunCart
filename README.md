# 🛒 SUNCART

> A modern Summer Essentials eCommerce platform built with Next.js 🚀

---

## 📌 Purpose

**SunCart** is a sleek and user-friendly eCommerce web application where users can explore summer essential products, view detailed information, and enjoy a smooth shopping experience with authentication and modern UI.

---

## ✨ Key Features

- ✅ Browse summer essential products with a modern UI  
- ✅ Product details page with dynamic routing  
- ✅ Add to cart / product interaction system  
- ✅ Secure authentication system  
- ✅ User profile page with update functionality  
- ✅ Toast notifications for better UX  
- ✅ Loading states & error handling  
- ✅ Fully responsive design (mobile + desktop)  
- ✅ Clean and modern UI with HeroUI components  

---

## 🛠️ Tech Stack

- ⚡ Next.js (App Router)
- 🎨 Tailwind CSS
- 🧩 HeroUI
- 🔥 React Hot Toast
- 🔐 Better Auth / Auth Client
- ▲ Vercel (Deployment)
